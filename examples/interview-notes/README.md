# Interview Note Fixtures

These fixtures are fictional and safe to commit. They are designed for testing typed interview intake and uploaded-audio metadata without storing real recordings, real transcripts, recruiter messages, or private candidate details.

Use these files as local demo inputs:

- `phone-screen.md`: fictional recruiter screen notes.
- `technical-round.md`: fictional technical interview notes.
- `audio-upload-metadata.json`: metadata for a pretend uploaded audio file; the audio file itself is intentionally absent.

Privacy contract:

- Transcript text is private user context.
- Interview fixtures are not public evidence.
- Interview transcripts must not appear in `sourceUrls`.
- Real voice recordings, names, phone numbers, emails, cookies, or tokens must never be committed.
