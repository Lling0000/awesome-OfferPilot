# Changelog

All notable changes to OfferPilot will be tracked here.

The format is inspired by Keep a Changelog, and this project uses semantic versioning once versioned releases begin.

## [Unreleased]

### Added

- Public package metadata for discovery, classifiers, project URLs, and maintainer information.
- CI coverage across supported Python versions with pip caching, package build checks, and strict publish verification.
- Support, code of conduct, and issue template guidance for safe public contribution.
- Content-aware `offerpilot doctor --strict-publish` checks for package, CI, and community readiness.

### Changed

- Pull request and issue templates now ask for clearer evidence, privacy, support, and adapter test details.

## [0.1.0] - 2026-06-01

### Added

- Local-first OfferPilot MVP with mock-backed job-search tracking, interview preparation, daily intelligence, reminders, and evidence-backed reports.
- `offerpilot doctor --strict-publish` for repository readiness checks.
